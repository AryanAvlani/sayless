# Face ID reel — sources
- "More than thirty thousand invisible dots": Apple Newsroom, "The future is here: iPhone X" (12 Sep 2017) — "Face ID projects more than 30,000 invisible IR dots." https://www.apple.com/newsroom/2017/09/the-future-is-here-iphone-x/
- Dot projector + infrared camera + flood illuminator; depth map + infrared image: same Apple Newsroom release; Apple Platform Security "Face ID and Touch ID security" ("projects and reads thousands of infrared dots to form a depth map of the face along with a 2D infrared image") https://support.apple.com/guide/security/sec067eb0c9e
- Photos can't pass (no depth): Apple Support "About Face ID advanced technology" (Face ID matches against depth information, which isn't found in print or 2D digital photographs) https://support.apple.com/102381
- On-device, not cloud: Apple Newsroom 2017 ("all of the processing is done on-device and not in the cloud")
- Less than 1 in 1,000,000: Apple Support "About Face ID advanced technology" (random person, single enrolled appearance; higher for twins/siblings/under 13) https://support.apple.com/102381
