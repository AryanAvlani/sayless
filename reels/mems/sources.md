# Screen-rotation (accelerometer) reel — sources
- Package 2 mm × 2 mm × 0.95 mm (example phone-class accelerometer): Bosch Sensortec BMA400 datasheet — https://cdn.sparkfun.com/assets/e/9/e/6/0/BMA400-Datasheet.pdf
- Proof mass on springs (tethers), interdigitated fixed/moving fingers, capacitance changes with displacement: Analog Devices ADXL description (US patent 6651027 text); All About Circuits capacitive accelerometer explainer
- Finger widths of a few µm: arXiv 2508.12249 (electrode finger width 4 µm)
- Output data rates of hundreds of Hz; 3 axes: BMA400 datasheet / DigiKey listing (3 Hz–384 Hz bandwidth, X/Y/Z)
- Output data rate 12.5–800 Hz; built-in step counter: BMA400 datasheet (Technical data) — https://datasheet.chipsmall.com/BMA400/559443.pdf
